Privacy Policy

Last updated: November 1, 2026

Rio Tells It makes short animated videos. To publish them, we use a small private tool (shown as "Rio Poster" or "Rio Bot" on sign-in screens) that uploads our own videos to our own accounts on YouTube, TikTok, Instagram and Facebook.

Who uses the tool

Only the owner of the Rio Tells It channel. The tool is not offered to the public, and nobody else signs in to it.

What information it uses

  • Sign-in permissions for the Rio Tells It accounts only, used to upload videos, add titles, captions and hashtags, and read the channel's own name to confirm it is posting to the right place.
  • It does not collect, store or share personal information about viewers or any other people.

How it is stored

Sign-in codes are kept in secure, encrypted storage (the owner's computer's password store and encrypted GitHub secrets). They are never sold or shared, and are used only to post Rio Tells It videos.

Use of Google data

Rio Poster's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses the YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time from the account's security settings, for example Google's third-party access page.
